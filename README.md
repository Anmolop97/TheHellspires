## 🚀 Overview

**Coditech** is a high-craft developer workspace designed to turn cryptic compiler, runtime, and shell errors into clear, verified solutions. It operates on an **offline-first hybrid architecture**:
1. **Instant 14,800+ Offline Rules Engine**: Runs 100% locally in the browser with sub-millisecond lookup latency (`< 0.1ms`). No code ever leaves your machine during Quick Diagnosis.
2. **Nova AI Avatar Companion**: A vector-rendered procedural mascot reacting to diagnosis states in real time.
3. **Optional Gemini AI Escalation**: Seamlessly escalate to Google Gemini 1.5 Flash for multi-file root cause analysis and custom bug fixing.

---

## ✨ Features

- **⚡ Sub-Millisecond Diagnostics**: 14,800+ curated error rules across 18+ programming languages and dev tools.
- **🛡️ 100% Client-Side Privacy**: Offline regex & language-indexed hash trie ensures zero data transmission for local fixes.
- **🎨 Emil Kowalski Motion Craft**: Spring-physics transitions (`scale(0.95)`, damping `30`, stiffness `400`) and tactile feedback.
- **📦 Multi-Ecosystem Coverage**:
  - **Python**: Core exceptions, PyTorch CUDA OOM, Pandas, Django, FastAPI.
  - **JavaScript & TypeScript**: Full Microsoft TS Compiler registry (`TS1000`–`TS8000`), V8 runtime.
  - **React & Next.js**: Hydration mismatches, Hook rules, Server Actions.
  - **DevOps & Containers**: Docker port collisions, Kubernetes CrashLoopBackOff, Git non-fast-forward.
  - **Systems & DBs**: C/C++ Segfaults, Rust borrow checker, Go nil pointers, PostgreSQL SQLSTATE, MySQL.
  - **Swift & PHP**: Swift optional unwrapping, Laravel exceptions.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS v4 (Dark Theme `#060911` with Emerald/Cyan accents)
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Avatar System**: `@bible-strong/avatar-react` + `@bible-strong/avatar-core`
- **Serverless API**: Vercel Serverless Function (`api/debug.js`)

```bash

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Build for production
npm run build
```
